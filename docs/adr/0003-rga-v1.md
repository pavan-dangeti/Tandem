# ADR 0003: Sequence CRDT — RGA chosen for v1

## Status

Accepted (Phase 2)

## Context

ADR 0001 chose Fugue after evaluating RGA. During implementation we needed a
sequence CRDT that we can verify rigorously with property-based and
model-based tests against an independent reference implementation.

## Decision

RGA for ordered collections in v1. Text runs display interleaving of
concurrently typed runs (the classic RGA weave), which is acceptable at v1
because whiteboard text is short and the convergence guarantee (safety) is
the property that matters most; the alternative (incorrect Fugue) would be
worse.

## Rationale

- RGA's rule is small and total: parent = insertion predecessor, siblings
  ordered by (counter, actor) descending. It is short enough to re-derive
  correctly in a reference implementation and to property-test
  exhaustively.
- Fugue's integration walk is easy to get subtly wrong; a wrong sequence
  CRDT breaks convergence, the core safety property. We prefer a correct
  RGA now to a subtly broken Fugue.
- The weave artifact only shows for concurrent insertion runs at the same
  position — a rare case in whiteboard text.

## Consequences

- Concurrent same-position text runs may interleave; documented in the
  README limitations.
- Z-order of concurrent appends stays deterministic.
- Fugue remains a candidate v2 upgrade; the position identifiers slot into
  the same interface.
